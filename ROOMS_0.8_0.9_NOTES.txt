0.8 // CONNECTED ROOM MAPS
  - Ordinary layers (Layers 1-4 of Boot Sector, The Heap, /dev/null, Nexus Complex) are fixed, authored maps. Edit MAPS in rooms.js.
    Notation: letter = room (S entry, C combat, X exit node, E challenge, T treasure, $ shop), '-' joins side by side, '|' joins above/below.
  - Each room reuses an existing world arena (derived copy with walls/hazards cut around the doors so they are reachable; safe rooms also lose
    hazards and central walls). Exit nodes use the layer's own arena, so each layer keeps its identity.
  - Doors are tinted by what is behind them (E / $ / T labelled), red and locked while a room is hostile, open when cleared. Minimap bottom-right.
  - Cleared rooms stay cleared (state lives on G.cfg.map); safe rooms never spawn enemies. HP / deck / pipeline / shield carry through doors.
  - Exit node: clear it (swarm, or the existing hack / data-core objective), then step on the NEXT LAYER portal -> the ORIGINAL layer reward screen.
  - Boss layers (5), Deadlock, generated worlds and the sandbox are untouched (single room, same arenas, same progression).
  - Kernel is the only sector that gets procedurally generated maps (genKernelRooms), new every layer.
  - Safe Round / Elite Hunt page and its handler are gone; no layer shows a choice screen now.

0.9 // SPECIAL ROOMS
  - Challenge room (E): elite encounter, 5 Cycles, then the normal reward screen with the Elite Hunt rarity table (uncommon or better), then you
    return to the room.
  - Treasure cache (T): interact (E key / OPEN button) -> 3-card choice + 1-3 Cycles. Flagged looted before the reward opens, so it cannot pay twice.
  - Cycle Shop ($): the merchant (cyborg with an LED broom, drawn with canvas shapes, no sprites) is always in the room with a counter, a slot machine
    and an rand() odds board. Talk to him -> Undertale-style menu: portrait, typewriter dialogue, BUY / SLOTS / LEAVE. cycles_shop plays on room entry.
  - BUY: 3 cards (existing card defs, same add-to-deck path as rewards, 15% chance one is 50% off), RESTORE() (+40% HP, stock 2), PATCH() (refill
    shield, stock 2), MYSTERY_CRATE() (random card, odds shown), REROLL_STOCK(). Wand / weapon shop NOT implemented; add a new category in
    buildShopStock() / shopRender() when the time comes.
  - Consumables: Q = RESTORE(), R = PATCH(), only in a cleared / safe room (never mid-fight).
  - SLOTS: bets 1 / 2 / 5, one roll per spin shown as cumulative rand() thresholds: <0.03 JACKPOT x10, <0.10 TRIPLE x4, <0.30 PAIR x2, else x0.
    Expected return 98%. The wager is deducted before the roll; the payout is applied once (also if you close the menu mid-spin).

CYCLES // WHAT WAS IMPLEMENTED
  Taken from the design notes: Cycles are the in-run currency (not Commits), carry between layers, and a redraw costs escalating Cycles per layer
  (1, 2, 3, ...) that resets each layer. Shop casino = slot reels with visible probability expressions.
  PROTOTYPE VALUES (rooms.js, CYCLES): start with 3; earn 2 per combat room, 3 per exit node, 5 per challenge, 1-3 from a chest.
  UNRESOLVED: the repository does not contain the earlier Cycles design, so these could NOT be recovered and are placeholders: starting balance,
  how Cycles are earned, any boss payout (CYCLES.earn.boss exists but nothing pays it yet), the real slot odds / payout table, the exact shop prices,
  and whether anything besides Redraw and the shop spends Cycles. Redraw used to be one free reroll per round; it now costs Cycles as above.
